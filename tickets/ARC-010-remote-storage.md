# ARC-010: Store information in multiple remote Archives

**Status:** MVP

## Goal

Provide remote storage and allow a user to work with multiple remote Archives, each identified by its URL.

## Desired outcomes

- Content can be written to and retrieved from a remote Archive.
- A user can configure and use more than one remote Archive.
- Each remote is addressable by its URL; possession of that URL is the MVP access model.
- Using multiple remote Archives is part of MVP; supporting multiple storage technologies is a separate future feature.
