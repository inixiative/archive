# ARC-005: Connect sessions to the work they concern

**Status:** Proposed goal

## Why this matters

A session is difficult to interpret in isolation. Task intent, code changes, review feedback, and project structure help explain what happened and whether it worked.

## Goal

Associate captured experience with available repository, branch, commit, pull request, Linear issue, and source identity context, with room for Atlas-style tags.

## Desired outcomes

- Relevant sessions can be found from the work they concern.
- People and agents can follow available links between session evidence, task intent, and resulting changes or reviews.
- Explicit associations and inferred associations are distinguishable; missing context remains visible.
- Incorrect associations can be corrected.

## Questions to resolve

Which associations are essential for the first retrospective, and which enrichment can wait?
